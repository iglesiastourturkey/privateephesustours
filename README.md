# Private Ephesus Tours

The 2026 redesign of [PrivateEphesusTours.com](https://privateephesustours.com/): an editorial, conversion-focused website for private Ephesus experiences from Kusadasi and Izmir.

## Brand direction

**Archaeological Editorial Luxury** — cultural depth and real local expertise, presented with the clarity expected from a high-performing shore-excursion website. The visual language is intentionally distinct from the cruise-planner identity of Kusadasi Port Tours and the immersive Turkey-wide identity of Iglesias Tour Turkey.

## Phase 1 — Homepage foundation

- responsive navigation and brand mark
- cinematic hero with direct WhatsApp planning CTA
- service trust strip
- “Your Day in Ephesus” narrative timeline
- four intent-led experience entry points
- private-versus-group comparison
- responsive mobile layout and reduced-motion support
- foundational SEO metadata

## Local development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

Production validation:

```bash
npm run build
```
